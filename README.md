# Lab 1 — Insurance dataset

## Описание данных
Набор `insurance.csv` содержит сведения о возрасте, поле, индексе массы тела,
количестве детей, статусе курения, регионе проживания и индивидуальных медицинских
расходах (`charges`). Проверьте фактические столбцы файла перед сдачей работы.

Источник: Kaggle — укажите ссылку на конкретную страницу набора данных.

## Библиотеки
- `pandas` — чтение CSV, анализ структуры, проверка типов, пропусков и дубликатов.
- `matplotlib` — построение и настройка графиков.
- `seaborn` — статистические визуализации и цветовые палитры.

## Методы предобработки
- `pd.read_csv()` — загрузка файла.
- `head(3)` — просмотр первых строк.
- `info()`, `dtypes` — проверка типов и структуры.
- `isna().sum()` — подсчёт пропусков.
- `duplicated().sum()` — подсчёт дубликатов.
- `pd.to_numeric(..., errors='coerce')` — преобразование столбцов в числовой тип;
  некорректные значения переводятся в `NaN`.
- `groupby('region').size()` — подсчёт записей по регионам.

## Визуализации
1. Горизонтальная столбчатая диаграмма количества записей по регионам.
2. Гистограмма распределения медицинских расходов.
3. Диаграмма размаха расходов по статусу курения.
